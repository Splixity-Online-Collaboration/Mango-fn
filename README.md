# Mango-fn

🥭 Mango is a small Desktop UI [DSL](https://en.wikipedia.org/wiki/Domain-specific_language) which you can use to make beautiful desktop apps!

### Example
```mg
window "My App" {
  button "click me for infinite cookies"
}
```

## Quick Start

1. Grab the latest release, then place the unzipped folder somewhere safe.
2. Add the Mango.exe located in that folder into your `PATH` system env variable.
3. Create your mango file, e.g `myapp.mg` (ensuring icons are in the same project root)
4. run your project via `mango myapp.mg`
